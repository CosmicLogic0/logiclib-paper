# LogicLib for Paper changelog

## 0.1.0
- First version. One jar for Paper 1.12.2 to 26.3 (built for Java 8, compiled against the 1.13.2 API).
- LogicVersion: which Minecraft version the server runs (old and year-based numbers).
- LogicConfigs: config.yml with new keys added automatically.
- LogicText: colored chat messages with a prefix.
- LogicParticles: per-player colored particle lines, boxes and circles on every version.
